# operator-vault

Personal data tree for the [operator-core-mini](https://github.com/snackdriven/operator-core-mini)
substrate. **Private repo.** Generated by
[`tools/bootstrap_vault.py`](https://github.com/snackdriven/operator-core-mini/blob/main/tools/bootstrap_vault.py).

## Layout

```
backpack/         active carry-state (current/, recent/, pinned/, evergreen/, _replaced/)
doctrine/         pinned truths (identity, defaults, voices, routing, policies)
hoard/            write-once archive — aged-out items live here forever
policy/           freshness bands + TTL presets + renderer budgets
.github/workflows/
  expire.yml      nightly TTL daemon — moves expired backpack items to hoard/
  today.yml       morning render — writes today.md / today.statusline.txt
today.md          (committed by the morning workflow; not by hand)
today.statusline.txt
today.narrator-prompt.md
```

## How to use

### Run the console / Carry locally

The vault is just files; clone it and point the operator-core-mini console
at it.

```bash
git clone https://github.com/snackdriven/operator-core-mini.git ~/code/ocm
git clone <vault-url> ~/code/operator-vault
python ~/code/ocm/console/server.py ~/code/operator-vault
# open http://127.0.0.1:8765/      (full console)
# open http://127.0.0.1:8765/carry (todo app)
```

When you're done for the day:

```bash
cd ~/code/operator-vault && git add -A && git commit -m "evening" && git push
```

### The two GitHub Actions

**`expire.yml`** runs nightly at 23:55 UTC. It checks out this repo + a
fresh copy of `operator-core-mini`, runs `tools/expire.py .`, commits any
demote moves, and pushes. Pinned items and items without `ttl_seconds`
are exempt.

**`today.yml`** runs every morning at 12:30 UTC (~ 7:30 CDT). It renders
`daily-brief`, `narrator-brief`, and `statusline` against the current
state and commits `today.md`, `today.narrator-prompt.md`, and
`today.statusline.txt` to the repo root. Browse them in the GitHub UI on
your phone — markdown renders inline.

Both workflows pin operator-core-mini to `main` by default. Edit the
`ref:` in each workflow if you want to lock to a release.

### Requirements

- Actions enabled (Settings → Actions → General → "Allow all actions").
- Nothing else. Default `GITHUB_TOKEN` is enough for self-checkout +
  self-push. No PAT needed unless you want the Pages variant (see
  the operator-core-mini `deploy/README.md`).

## What this repo *does not* contain

- The renderers themselves (they live in `operator-core-mini/renderers/`).
- The console UI / Carry app (also in `operator-core-mini`).
- The daemon (also there). Workflows pull a fresh copy each run so this
  repo stays minimal.

## Hand-edit the doctrine

`bootstrap_vault.py` writes 9 schema-clean doctrine seeds. They run, but
they don't know you yet. After your first commit, walk through:

1. `doctrine/identity/user-profile.md` — name, role, support style.
2. `doctrine/default/writing-preferences.md` — your tone constraints.
3. `doctrine/voice/voice-good-place.md` and `voice-mass-effect.md` —
   pick a default register.
4. `doctrine/policy/consent-*.md` — what's allowed where.

Edit, commit, push. Renderers pick the change up on their next run.
